# Code of conduct

We want Skillkeeper to be a useful, welcoming project for maintainers, operators, researchers, and first-time contributors.

Be respectful, specific, and evidence-led. Critique ideas and implementations rather than people. Do not harass, threaten, discriminate, expose private information, or submit private agent traces without authorization.

Maintainers may edit or remove contributions and restrict participation when behavior harms the community or its users. Report conduct concerns privately through the repository owner's GitHub profile or private security reporting when sensitive information is involved.
